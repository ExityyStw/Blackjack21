# Blackjack 21 - Hack the Favela 2026

Este projeto é um jogo de baralho Blackjack ("21") desenvolvido em Java como parte da avaliação técnica para o **Hack the Favela 2026**.

## 🚀 Sobre o Projeto

O objetivo principal foi construir um simulador funcional de Blackjack que demonstrasse lógica de programação, organização de código e aplicação de conceitos de Orientação a Objetos (POO).

### Funcionalidades Implementadas:
- **Estrutura de Classes:** Representação clara de Cartas, Baralho e Jogadores.
- **Lógica de Jogo:** Sistema de embaralhamento aleatório e distribuição de cartas.
- **Interface Console:** Interação fluida via terminal para compra de cartas (hit) ou parada (stay).
- **Cálculo de Pontuação:** Verificação em tempo real da soma dos pontos e validação do status (Abaixo, Igual ou Acima de 21).

## 🛠️ Tecnologias e Ferramentas

O projeto foi desenvolvido utilizando as seguintes tecnologias:
- **Java JDK 21**: Linguagem principal.
- **IntelliJ IDEA**: Ambiente de desenvolvimento (IDE).
- **Git & GitHub**: Controle de versão e hospedagem.

### ✨ Processo de Desenvolvimento
O projeto foi desenvolvido com pesquisa, estudo e auxílio de ferramentas de apoio ao aprendizado.

## 📦 Como executar

1. Certifique-se de ter o Java instalado em sua máquina.
2. Clone o repositório:
   `git clone https://github.com/ExityyStw/Blackjack21.git`
3. Execute o arquivo principal `Blackjack.java` através do seu terminal ou IDE favorita.
